## 1. 결론 먼저

> 🟡 **v2(유료 신호)보다 명백히 낫다. 하지만 "좋은 사업"이라기보다 "해볼 만한 사업"이다.**
>
> - **긍정**: 진입 시장은 레드오션이지만, **한국 특화 축(김치프리미엄 이력 + 국내 거래소 비용
>   모델 + 한국어)** 은 실제로 비어 있다. 그리고 **과최적화 방지**라는 각도는 글로벌에서도
>   제대로 하는 곳이 드물다. 우리는 그 도구를 이미 만들었고, 그것으로 자기 전략을 세 번
>   기각한 이력이 있다 — 복제하기 어려운 종류의 신뢰다.
> - **부정**: 리테일 백테스팅 도구는 **지불의사가 낮고 이탈률이 높은** 카테고리다.
>   TradingView 가 월 $12.95 부터 시작하는 상황에서 가격 우위를 만들기 어렵고,
>   **거래소 데이터 재배포 약관**이 사업 구조 자체를 막을 수 있는 단일 최대 리스크다.
> - **판정**: **좁은 비치헤드로 시작하면 유효하다.** "전 세계 모든 코인 백테스팅 플랫폼"으로
>   시작하면 실패 확률이 높다. **"업비트 트레이더를 위한 김프·국내비용 기반 전략 검증기"** 로
>   시작하면 살아남을 확률이 유의미하게 올라간다.

## 2. 시장 정의와 규모

### 2-1. 우리가 파는 것의 정확한 카테고리

우리는 세 시장 중 **어디에도 정확히 속하지 않는다.** 그게 기회이자 위험이다.

| 시장 | 대표 | 우리와의 관계 |
| --- | --- | --- |
| 차트·분석 플랫폼 | TradingView | **가장 큰 대체재.** 백테스트가 딸려 있다 |
| 자동매매 봇 | 3Commas, Cryptohopper, Coinrule | **인접**. 봇이 본체, 백테스트는 부가 기능 |
| 온체인·데이터 | CryptoQuant, CoinGlass, Glassnode | **인접**. 데이터가 본체, 검증 도구는 없음 |
| **전략 검증 전문** | Backtrex, TrendSpider, StratBase | **우리 자리.** 시장은 작지만 비어 있는 쪽 |

### 2-2. 규모 — 한국을 비치헤드로 볼 때

거칠게 계산한다. 정밀한 숫자보다 **자릿수**가 의사결정을 좌우한다.

| 층 | 추정 | 근거·가정 |
| --- | ---: | --- |
| 국내 가상자산 계좌 보유자 | **약 1,600만 명** | 2025년 초 기준 국내 주요 거래소 계좌 보유자 (인구의 약 1/3) |
| 그중 능동적 트레이더 | 5~10% → **80만~160만 명** | 단순 보유가 아니라 정기 거래하는 층 (가정) |
| 그중 "전략·지표"에 관심 | 5~10% → **4만~16만 명** | 지표·전략 커뮤니티 활동 규모에서 유추 (가정) |
| **그중 유료 도구 지불 의향** | 3~7% → **1,200~1.1만 명** | 리테일 SaaS 전환율 통상 범위 (가정) |

**국내 유료 도달 가능 상한이 대략 1천~1만 명 규모다.**
월 2만원 기준 **연 매출 2.9억~26억원**의 범위인데, 이건 *상한*이지 기대값이 아니다.
현실적 초기 목표는 이 범위의 하단에서도 아래쪽 — **유료 200~500명(월 400~1,000만원)** 을
1~2년 안의 "생존 가능선"으로 잡는 것이 정직하다.

> **자릿수가 말하는 것**: 이건 **1인~소수 인원이 운영하는 지속 가능한 SaaS** 의 크기지,
> 투자를 받아 스케일할 크기가 아니다. 그렇게 목표를 잡으면 의사결정이 훨씬 선명해진다 —
> 광고비를 쓰지 않고, 커뮤니티와 콘텐츠로 얻고, 고정비를 낮게 유지한다.

일본어·영어 확장(이미 언어팩 구조가 계획에 있다)은 상한을 늘리지만, **김프 축이 통하지 않는
시장**이라 차별점이 하나 사라진다. 확장은 국내에서 증명한 뒤의 이야기다.

### 3-2. 경쟁 강도를 정직하게 본다

**TradingView 가 이 시장의 중력이다.** 월 $12.95 부터 시작하고, 차트·알림·커뮤니티·
스크리너가 전부 들어 있다. 백테스트만 놓고 우리가 더 낫다고 해도, 사용자는 **도구를 하나
더 결제해야 하는 이유**를 물을 것이다. 그 답이 명확하지 않으면 아무것도 팔리지 않는다.

다만 TradingView 에는 실질적 빈틈이 있다.

1. **Pine Script 를 써야 한다.** 이게 노코드 대안 시장(Backtrex, TrendSpider)이 존재하는
   이유 자체다. 코딩을 못 하는 트레이더가 이 시장의 다수다.
2. **과거 봉 수가 요금제에 묶여 있다** (Basic 5,000봉 → Ultimate 40,000봉).
   5분봉 5,000봉은 **17일**이다. 무료·저가 요금제로는 의미 있는 백테스트가 사실상 불가능하다.
3. **김치프리미엄이 없다.** 커스텀 심볼 조합으로 흉내낼 수는 있으나, 실환율이 아니라
   `USDT/KRW` 로 계산하면 값이 상쇄된다 — 우리가 Step 15 에서 직접 겪은 함정이다.
4. **결과의 신뢰도를 말해 주지 않는다.** Strategy Tester 는 좋은 숫자를 잘 보여주지만
   "이게 우연일 확률"은 말하지 않는다.

**봇 3사(Coinrule·3Commas·Cryptohopper)는 우리 경쟁자가 아니다.** 그들의 상품은
*자동매매 실행*이고 백테스트는 그 부가물이다. 게다가 그들은 **고객 거래소 API Key 를 받는다** —
`docs/LEGAL.md` 가 우리에게 절대 하지 말라고 한 구조다. 우리가 그쪽으로 가지 않는 한
직접 충돌하지 않는다. **대신 그들이 "봇으로 돈을 벌어준다"는 훨씬 강한 약속을 하기 때문에,
같은 지갑을 놓고 경쟁하는 것은 맞다.**

**CryptoQuant 는 참고할 가격 사례다.** $39/$109/$799 로 리테일부터 기관까지 층을 나눴고,
한국 회사이며 국내 인지도가 있다. **다만 백테스트 기능이 없다.** 데이터를 팔지 검증을 팔지 않는다.
→ 우리 포지션과 정면 충돌하지 않고, 오히려 **"CryptoQuant 로 본 것을 우리 도구로 검증한다"** 는
서사가 가능하다.

**국내 김프 사이트들은 전부 무료 실시간 위젯이다.** 김프가·코인섹트·코인투빗 등이
현재 프리미엄을 보여주지만, **과거 이력을 시계열로 주거나 그걸로 백테스트하게 해 주는 곳은 없다.**
CryptoQuant 가 Korea Premium Index 차트를 제공하지만 차트일 뿐 검증 도구가 아니다.

> **이 문단이 이 문서에서 가장 중요하다.**
> "김치프리미엄을 백테스트 조건으로 쓸 수 있는 서비스"는 조사 범위 안에서 **하나도 없었다.**

## 4. 우리가 들어갈 빈틈 3개

### 빈틈 ① 김치프리미엄의 이력화 — 가장 방어력 있는 축

- 국내 사이트: 실시간만. 이력 없음. 백테스트 불가.
- 해외 사이트: 애초에 관심 없음(그들 유저의 문제가 아니다).
- CryptoQuant: 차트는 있으나 검증 도구가 없고, 상위 요금제에 묶여 있다.

우리는 **BTC·ETH 일봉 3,267일치 김프 시계열을 이미 계산해 봤고**, 그 값이 단조적 구조를
갖는다는 것도 확인했다(하위 20% 승률 59.1% vs 상위 20% 39.2%). **이건 우리만 가진 실측이다.**

**해자의 크기**: 중간. 기술적으로 복제 가능하다(환율 API + 업비트 API면 된다).
하지만 **해외 서비스가 이걸 만들 동기가 없고, 국내 무료 사이트는 백테스트 엔진이 없다.**
그 사이의 공백이 우리 자리다. 시간을 벌어 주는 해자지 영구적인 해자는 아니다.

### 빈틈 ② 과최적화 방지를 제품의 전면에 놓는 것

조사한 어떤 경쟁 서비스도 **워크포워드 자동 실행 · 시도 횟수 카운터 · 홀드아웃 잠금**을
기본 기능으로 제공하지 않는다. 업계 담론에서는 과최적화가 끊임없이 논의되는데
(*"수익성 있는 백테스트의 90%는 통계적으로 무효"* 류의 글이 계속 나온다),
**도구는 그 문제를 사용자에게 떠넘긴다.**

이유는 명백하다 — **좋은 결과를 안 보여주는 도구는 안 팔릴 것 같기 때문이다.**
그게 정확히 우리의 베팅이다. 진지한 트레이더는 자기가 속고 있다는 걸 안다.

**해자의 크기**: 중간~큼. 기능 자체는 복제 가능하지만, **이건 기능이 아니라 제품 철학이라
복제하면 자기 마케팅과 충돌한다.** "우리 도구로 만든 전략은 대부분 못 씁니다"라고
말할 수 있는 회사는 많지 않다.

### 빈틈 ③ 국내 거래소 비용 모델

업비트 수수료 0.05%×2 + 슬리피지 → 왕복 약 0.20%. 해외 도구는 대개 바이낸스 기준
0.1% 이하로 계산하거나 아예 비용을 무시한다.

우리 실측이 보여준 것: **거래당 기대값 +0.20% vs 왕복 비용 0.18~0.20%** — 비용이
기댓값을 통째로 먹었다. **국내 트레이더에게 비용을 정확히 반영하지 않은 백테스트는
거짓말이다.** 이걸 기본값으로 하는 서비스가 없다.

**해자의 크기**: 작음. 하지만 ①과 합치면 "국내 트레이더 전용"이라는 포지션이 완성된다.

## 5. 차별점을 냉정하게 재검토

각 차별점에 대해 **"경쟁사가 3개월 안에 따라할 수 있나"** 를 묻는다.

| 차별점 | 복제 난이도 | 냉정한 평가 |
| --- | --- | --- |
| 김프 이력 + 백테스트 필드 | **낮음** (기술적으로) / **높음** (동기 측면) | 해외는 안 만들고 국내는 못 만든다. **시간을 버는 해자** |
| 과최적화 5개 장치 | 중간 | 기능은 복제 가능하나 **철학은 복제하면 자기모순** |
| 검증 아카이브(우리 실패 공개) | **높음** | 실제로 여러 번 실패하고 그걸 기록해 둔 이력이 필요하다 |
| 국내 비용 모델 | 낮음 | 단독으로는 약함 |
| 뉴스 롱숏 투표 시계열 | **높음** (시간이 필요) | 1년 뒤에는 아무도 못 따라온다. **지금 시작해야 한다** |
| 한국어 UI | 낮음 | 진입장벽은 되지만 차별점은 아님 |
| 전 코인 5분봉 웨어하우스 | 중간, **비용 큼** | **차별점이 아니라 원가다.** 여기에 자원을 몰면 진다 |

> **가장 중요한 재검토 결과**: 사용자가 전제 1 로 제시한 *"모든 코인 전 이력 적재"* 는
> **차별점이 아니라 비용 항목이다.** 이것 자체로는 아무도 돈을 내지 않는다.
> 돈을 내게 하는 것은 ①②⑤ 이고, 웨어하우스는 그것을 가능하게 하는 하부구조일 뿐이다.
> → **기획서 §3-3 의 "상위 100 코인 + 업비트 전 종목부터"** 권고가 여기서 나온다.

## 6. 지불의사(WTP) 현실 점검 — 가장 아픈 부분

리테일 백테스팅 도구는 **구조적으로 지불의사가 낮다.** 이유가 셋이다.

1. **"쓰고 나면 끝"이라는 성질.** 전략 하나를 검증하고 나면 다음 달에도 결제할 이유를
   만들어야 한다. 차트 구독(TradingView)은 매일 쓰지만 백테스트는 안 그렇다.
   → **대응**: 실시간 필드(김프 분위·펀딩·뉴스 투표)를 **모니터링 화면**으로도 제공해
   "매일 여는 이유"를 만든다. 검증만 파는 도구는 이탈한다.
2. **성과가 안 나면 도구 탓을 한다.** 우리 도구는 정직하게 "이 전략은 못 씁니다"라고
   말하는데, 사용자는 그 말을 듣기 위해 돈을 내지 않는다.
   → **대응**: 실패 판정을 **"당신이 손실을 피했습니다"** 로 프레이밍한다. 기각한 전략의
   가상 손실을 누적해 보여준다: *"이 도구가 지금까지 걸러낸 전략들의 예상 손실 −18.4%."*
   이게 있으면 구독 유지 이유가 숫자로 존재한다.
3. **무료 대체재가 강력하다.** TradingView 무료 + Python + ccxt 조합이면 개발자는 공짜로 한다.
   → **대응**: 우리 타깃은 **개발자가 아니다.** 코딩 없이 검증하고 싶은 트레이더다.
   이 구분을 흐리면 아무에게도 안 팔린다.

**가격 결정 관점**: PRO 19,900원은 TradingView Essential($12.95 ≈ 1.8만원)과 거의 같다.
"TradingView 대신"이 아니라 **"TradingView 에 더해서"** 결제하게 만들려면 그 가격이
심리적 상한이다. 3만원을 넘기면 저항이 급격히 커진다.

## 7. 진입 전략 — 좁게 시작한다

### 7-1. 비치헤드 정의

> **"업비트에서 거래하는, 코딩을 못 하는, 자기 규칙이 있는 한국인 트레이더"**

이 정의는 의도적으로 좁다. 넓히면 다음이 전부 흐려진다.

| 요소 | 이 정의가 만드는 것 |
| --- | --- |
| 업비트 | 김프 축이 자동으로 의미를 갖는다. 비용 모델이 정확해진다 |
| 코딩 못 함 | Pine Script 대안이라는 포지션이 선다. 개발자와 경쟁하지 않는다 |
| 자기 규칙이 있음 | "정답을 달라"는 유저를 처음부터 배제한다 — **v2 가 실패한 지점** |
| 한국인 | 한국어·한국 시간대·원화 결제·국내 커뮤니티 채널 |

### 7-2. 초기 획득 경로 (광고비 없이)

1. **검증 아카이브를 콘텐츠로 발행한다.** "김치프리미엄으로 매매하면 정말 될까 — 3,267일
   실측" 같은 글은 **국내에 실측 데이터가 없어서** 자체로 유입이 된다. 각 글 끝에서
   "직접 해보기" 버튼이 워크벤치로 연결된다. **우리 실패 기록이 그대로 마케팅 자산이다.**
2. **무료 등급을 진짜로 쓸 만하게 만든다.** 일봉·시간봉 + 최근 1년 + 하루 5회는
   아이디어 하나를 온전히 검증할 수 있는 양이다.
3. **본인이 먼저 쓴다.** 2026-09-04 "관리자 우선" 결정 그대로. 만든 사람이 매일 안 쓰는
   도구는 팔 수 없다.

### 7-3. 하지 말아야 할 것

| 하지 말 것 | 이유 |
| --- | --- |
| 800코인 전 이력부터 채우기 | 아무도 안 쓰는 코인에 몇 주를 쓴다. 차별점도 아니다(§5) |
| 유저 성과를 마케팅에 쓰기 | 자본시장법상 **실현되지 않은 수익률 광고**. `docs/LEGAL.md` |
| 자동매매·API Key 로 확장 | 봇 3사와 정면 충돌 + 규제 리스크 급증. 명시적으로 금지된 방향 |
| 적중률·수익률을 헤드라인으로 | v2 가 실패한 자리로 되돌아가는 것 |
| 영어권 먼저 진출 | 김프 축이 죽는다. 차별점 3개 중 2개를 버리고 싸우는 셈 |

## 10. 최종 판정

**v2(유료 신호)와 v3(백테스팅 워크벤치)를 같은 기준으로 놓고 비교하면 이렇다.**

| | v2 유료 신호 | v3 워크벤치 |
| --- | --- | --- |
| 제품이 성립하려면 필요한 것 | **이기는 룰** (12구간 중 11구간 실패) | **정직한 측정** (이미 만들어 놓음) |
| 경쟁 우위 | 없음 — 적중률로 비교당함 | 김프 이력 + 과최적화 방지 + 국내 비용 |
| 법률 리스크 | 🟠 유사투자자문업 | 🟢 낮음 / 🔴 **데이터 약관은 더 높음** |
| 실패 시 남는 것 | 없음 | **데이터 자산 + 측정 도구** |
| 우리가 쓸 수 있는가 | 못 씀 (본인도 신뢰 못 함) | **매일 씀** |

마지막 행이 결정적이다. v2 는 만든 사람이 신뢰하지 못하는 제품이었다.
v3 는 만든 사람이 **이미 사흘 동안 매일 쓴** 제품이다 — Step 14·15·16·17 이 전부
이 도구를 손으로 돌린 기록이다.

> **판정: 전환한다. 단, 좁게.**
>
> 1. **G0(데이터 약관)을 가장 먼저 확인한다.** 여기서 막히면 다른 모든 계획이 무의미하다.
> 2. **유니버스를 상위 100 + 업비트 전 종목으로 시작한다.** 전 코인 적재는 차별점이 아니다.
> 3. **과최적화 방지 장치를 처음부터 넣는다.** 나중에 붙이면 안 붙는다.
> 4. **기대치를 "1인 지속 가능한 SaaS"로 잡는다.** 유료 200~500명이 성공이다.
> 5. **파생·뉴스·매크로 수집기는 지금 켠다.** 화면보다 먼저. 지나간 시간은 못 산다.
