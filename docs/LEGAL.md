## 한 문장 결론

> 🟠 **불법이라고 단정할 수준은 아니지만, 유료 BUY/SELL 신호 서비스라는 부분 때문에
> 자본시장법상 유사투자자문업 및 투자자문 관련 규제를 반드시 검토해야 하는 모델.**
>
> 🟢 **고객 자산을 운용하지 않고, 고객별 맞춤 조언을 하지 않으며, 다수 이용자에게 동일한
> 시장분석·통계·기술지표·모델 결과를 제공하는 분석 SaaS** 로 명확히 설계하면 현실적인 사업 모델.

핵심 원칙: **"투자자문을 판매한다"가 아니라 "분석 도구를 구독한다"** 는 구조.
그리고 **우리 서비스가 돈이나 코인을 만지지 않는 것.**

## 지금 구조에서 잘하고 있는 것 (유지할 것)

1. 고객의 돈을 받지 않음
2. 고객 계좌를 운용하지 않음
3. **고객 API Key 를 받아 자동매매하지 않음**
4. 본인 자동매매는 내부 기능으로만 사용
5. 다중 거래소 데이터 분석
6. 분석 근거를 사용자에게 공개
7. 백테스트와 실전 성과를 구분

> **고객 거래소 API Key 를 받는 구조로 발전시키지 말 것.** 규제 리스크가 크게 증가한다.

## 가장 위험한 지점 — 유료 BUY/SELL 신호

**유료 + 특정 코인 + BUY/SELL + 상승 가능성 + 투자 판단 근거** 가 합쳐지면 위험도가 올라간다.

- ❌ 개별 투자자문에 가까움: *"내가 500만원 있는데 BTC 사도 될까요?" → "매수하세요. 300만원을 매수하세요."*
- ⭕ 개별성 없는 정보 제공: **모든 사용자에게 동일하게** 제공되는 시장 분석 데이터

자본시장법의 유사투자자문업 정의에 **"개별성 없는 조언"** 이라는 표현이 있다. 우리 구조는
개별성 없는 정보 제공으로 설계할 여지가 크다.

**"AI 가 판단한 것이므로 당사는 투자자문을 하지 않습니다" 는 면책이 되지 않는다.**
면책 문구가 서비스 구조의 법적 문제를 해결해 주지 않는다.
**명칭만 바꿔서 실질적으로 투자자문을 하는 경우도 안전하지 않다.**

## 확률 표기

"5분 상승 가능성 **81%**" 는 *"AI가 81% 확률로 오른다고 보장한다"* 로 읽힐 수 있다.

- ❌ `BTC 상승 가능성 81%`
- ⭕ `단기 상승 방향성 Score: 81/100` 또는 `모델 신호 강도: 81/100`
- ⭕ `모델 추정 확률: 81%` **+ "과거 데이터 기반 모델 출력값이며 실제 미래 수익률을 보장하지 않습니다."**

## 백테스트

사업적으로 좋은 기능이지만 **마케팅을 잘못하면 문제가 된다.**
자본시장법은 유사투자자문업자가 **사실과 다른 수익률이나 실현되지 않은 수익률을 제시하는 광고**를 금지한다.

- ❌ `AI가 BTC 매매로 최근 1년간 127% 수익!` / `AI 신호 적중률 89%` / `이 시스템을 따라 하면 높은 수익`
- ⭕ 과거 데이터 기반 **시뮬레이션 결과**임을 명시, **과거 성과는 미래 수익을 보장하지 않음**,
  **수수료·슬리피지 반영 여부 / 백테스트 기간 / 데이터 출처 / 생존자 편향 여부**를 투명하게 표시

## 유사투자자문업 신고

현재 자본시장법상 유사투자자문업은 **신고제**다. 다만 권장 순서는:

> "일단 신고하고 뭐든 제공" ❌
> **서비스 구조를 먼저 법적으로 최대한 안전하게 설계한 뒤, 필요하면 신고 여부를 변호사·금융당국에 확인** ⭕

**신고 = 투자자문업을 자유롭게 할 수 있다는 의미가 아니다.** 개인별 투자상황에 맞춘 조언을
시작하면 이야기가 달라진다.

## 법률 밖이지만 출시 전 필수 확인

### 거래소 API 약관

> "API로 데이터를 가져올 수 있다" 와
> "그 데이터를 상업적 SaaS 에서 여러 고객에게 재배포할 수 있다" 는 **완전히 다른 문제**다.

거래소별로 확인: API Terms / Market Data Terms / Commercial Use / Redistribution /
Caching / Derived Data / Rate Limit

### TradingView Webhook

현재 설계(유저 본인 계정의 Alert 를 본인 대시보드로 중계)는 **시세를 긁어 재판매하는 구조와
다르므로 방향은 괜찮다.** 다만 출시 전 TradingView 약관에서 **Webhook 데이터를 상업 서비스에서
재가공·저장·표시하는 것이 허용되는지** 별도 확인 권장.
